# WHY IT WAS RETIRED
#   There were two authorities over one question. The catalog carried
#   `parallel.status` that nothing consulted, and `aid-bats-parallel-lane.sh`
#   consulted this list, which the catalog knew nothing about. Two authorities
#   is how a promotion outlives the evidence behind it: a plain list cannot
#   notice that a file it names has since acquired a lock or started writing a
#   shared path, so a file stays pooled long after the reason it was pooled has
#   stopped being true.
#
#   The catalog can notice. A migrated status carries the hash of the sources
#   it was verified against and a digest of the resources they touch. A change
#   to those resources reverts the unit to `unknown`, and it leaves the pool
#   with nobody editing anything. That reversion was demonstrated on this
#   repository's own catalog: adding a `flock` to a pooled file moved it from
#   `safe` to `unknown`, while a comment-only edit left it pooled.
#
# WHERE THE EVIDENCE WENT
#   The 72 paths this file used to list were migrated by
#   `scripts/aid-test-catalog-migrate-p071-allowlist.sh` with
#   `method: migrated_p071_step3`, so a migrated entry stays distinguishable
#   from a freshly piloted one, and an `evidence_ref` citing P071 Step 3 and
#   audit-20260802-070629.
#
#   That evidence_ref records the counts as MEASURED at migration time rather
#   than as this file's own header claimed them. The header stated that P066's
#   audit "read all 83 bats files"; the catalog holds 74 bats run units and the
#   tree holds more than either figure. Carrying "83" across would have turned a
#   documentation error into a durable schema field.
#
