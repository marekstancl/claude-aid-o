# Rubrika generičnosti referencí

Jeden seznam pro dvě místa: krok 2 podle něj vyřazuje generické reference z galerií,
krok 6 ho přidává k závěrečné revizi Impeccable. „Generické" je tak kontrola, ne vkus.
Cizí weby se posuzují touto rubrikou; detektor Impeccable je stavěný na náš kód
a zkouší se jen v dry runu.

## Tvrdá kritéria (vyřadit při jednom)

- SaaS sada karet: stejné zaoblené karty, jeden stín pod vším, gradientové podbarvení.
- Šablonový rám: ALL-CAPS nadpisek nad každým nadpisem, řetězce `A · B · C`, `→` na tlačítkách.
- Hero „velké číslo + malý popisek + gradient".
- Web se nenačte.
- Web schovaný za celoobrazovkovou cookie zdí.
- Web schovaný za přihlášením.

## Měkká kritéria (vyřadit při dvou)

- Krémové pozadí + patkové písmo + terakotový akcent.
- Skoro černé pozadí + jeden kyselý akcent.
- Vlasové linky a hustě sázené novinové sloupce.
- Značky 01/02/03 na něčem, co není posloupnost.
- Stejné vyjetí a vyblednutí na každé sekci.
- Jedno systémové písmo nebo Inter všude.

## Pravidla

- Reference, která splní jedno měkké kritérium, ale jinak je silná, zůstává.
- Rubrika nikdy nepřebíjí referenci, kterou PM dodal přes URL.
- Reference je inspirace (písmo, kompozice, barva, pohyb), nikdy šablona;
  kopírovat značku nebo layout 1:1 je zakázáno.
