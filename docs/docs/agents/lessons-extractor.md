# Lessons Extractor -- Removed in v2.0.0

This agent was consolidated into [Curator](./curator) in v2.0.0.

The Curator agent now handles both improvement proposals and lessons extraction in a single post-run pass (Phase 7: Lessons Extraction). Commands and insights are deduplicated against `command-history.md` and `lessons-learned.md`.
