# Security -- Removed in v2.0.0

This agent was consolidated into [Implementer](./implementer) (security role card) and [Verifier](./verifier) (security-review focus card) in v2.0.0.

- **Implementation role:** The implementer's `security` role card handles SAST scans, secrets checks, and security patches.
- **Verification focus:** The verifier's `security-review` focus card handles read-only security analysis and findings.

See [Role Cards](../skills/role-cards) for both card references.
