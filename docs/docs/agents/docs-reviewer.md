# Docs Reviewer -- Removed in v2.0.0

This agent was consolidated into [Verifier](./verifier) in v2.0.0.

The verifier agent uses focus cards from `role-cards.md` to adopt any verification focus. The `docs-review` focus card defines the same capabilities: endpoint documentation completeness, code example accuracy, CHANGELOG presence, and placeholder detection.

See [Role Cards](../skills/role-cards) for the full docs-review focus card reference.
