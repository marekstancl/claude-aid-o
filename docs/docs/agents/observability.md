# Observability -- Removed in v2.0.0

This agent was consolidated into [Implementer](./implementer) in v2.0.0.

The implementer agent uses role cards from `role-cards.md` to adopt any role. The observability role card defines the same capabilities: OpenTelemetry tracing, structured logging, business metrics, and trace context propagation.

See [Role Cards](../skills/role-cards) for the full observability role card reference.
