# Release -- Removed in v2.0.0

This agent was consolidated into [Implementer](./implementer) in v2.0.0.

The implementer agent uses role cards from `role-cards.md` to adopt any role. The release role card defines the same capabilities: semantic version bump, CHANGELOG entries, git tags, and release validation. Automated release operations are handled by `aid-release.sh`.

See [Role Cards](../skills/role-cards) for the full release role card reference.
