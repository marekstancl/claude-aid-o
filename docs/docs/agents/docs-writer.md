# Docs Writer -- Removed in v2.0.0

This agent was consolidated into [Implementer](./implementer) in v2.0.0.

The implementer agent uses role cards from `role-cards.md` to adopt any role. The docs-writer role card defines the same capabilities: API documentation, architecture guides, changelog entries, and README updates.

See [Role Cards](../skills/role-cards) for the full docs-writer role card reference.
