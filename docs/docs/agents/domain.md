# Domain -- Removed in v2.0.0

This agent was consolidated into [Implementer](./implementer) in v2.0.0.

The implementer agent uses role cards from `role-cards.md` to adopt any role (architect, backend, frontend, etc.). The domain role card defines the same capabilities: entity definitions, business invariants, state machines, and aggregate boundaries.

See [Role Cards](../skills/role-cards) for the full domain role card reference.
