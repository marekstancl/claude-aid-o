# Code Reviewer -- Removed in v2.0.0

This agent was consolidated into [Verifier](./verifier) in v2.0.0.

The verifier agent uses focus cards from `role-cards.md` to adopt any verification focus. The `code-review` focus card defines the same capabilities: module boundary compliance, error handling patterns, DRY violations, type safety, and performance review.

See [Role Cards](../skills/role-cards) for the full code-review focus card reference.
