# Architect -- Removed in v2.0.0

This agent was consolidated into [Implementer](./implementer) in v2.0.0.

The implementer agent uses role cards from `role-cards.md` to adopt any role (architect, backend, frontend, etc.). The architect role card defines the same capabilities: API contracts, ADRs, event schemas, and module boundaries.

See [Role Cards](../skills/role-cards) for the full architect role card reference.
