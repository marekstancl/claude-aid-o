# QA -- Removed in v2.0.0

This agent was consolidated into [Verifier](./verifier) in v2.0.0.

The verifier agent uses focus cards from `role-cards.md` to adopt any verification focus. The `qa` focus card defines the same capabilities: unit tests, integration tests, contract tests, and coverage verification.

See [Role Cards](../skills/role-cards) for the full QA focus card reference.
