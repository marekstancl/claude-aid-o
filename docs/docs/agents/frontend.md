# Frontend -- Removed in v2.0.0

This agent was consolidated into [Implementer](./implementer) in v2.0.0.

The implementer agent uses role cards from `role-cards.md` to adopt any role (architect, backend, frontend, etc.). The frontend role card defines the same capabilities: React/TypeScript components, API service layer, and RBAC guards.

See [Role Cards](../skills/role-cards) for the full frontend role card reference.
