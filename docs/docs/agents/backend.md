# Backend -- Removed in v2.0.0

This agent was consolidated into [Implementer](./implementer) in v2.0.0.

The implementer agent uses role cards from `role-cards.md` to adopt any role (architect, backend, frontend, etc.). The backend role card defines the same capabilities: REST/GraphQL endpoints, service logic, DB queries, and integrations.

See [Role Cards](../skills/role-cards) for the full backend role card reference.
