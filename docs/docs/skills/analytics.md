# Analytics -- Removed in v2.0.0

This skill was consolidated into the [Auditor](../agents/auditor) agent and [Pipeline](./pipeline) in v2.0.0.

Token efficiency tracking is now part of the Auditor agent's Token Efficiency Audit (category H). Execution metrics are recorded in `timeline.jsonl` and `state.yaml` during pipeline runs.
