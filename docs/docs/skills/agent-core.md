# Agent Core -- Removed in v2.0.0

This skill was renamed and refocused as [Agent Protocol](./agent-protocol) in v2.0.0.

The agent-protocol skill covers the universal I/O format, evidence writing, error handling, git discipline, and scope enforcement that all agents follow. Run-start protocol and role detection logic moved to [Run Management](./run-management) and [Pipeline](./pipeline).
