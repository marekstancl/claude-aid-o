# Memory

The memory skill defines how AID agents access project context and persistent knowledge. It covers file-based memory (always available) and optional Qdrant vector memory (for cross-project knowledge).

## Purpose

Agents need context to make good decisions: what the project looks like, what was done recently, what commands work, what lessons were learned, and what is in the backlog. The memory skill standardizes how this context is accessed across all agent types.

## File-Based Memory (Always Available)

### Project Profile
- **Path:** `.aid-o/config/project.yaml`
- **Read at:** every run start
- **Contains:** name, type, languages, test/lint/build commands, framework
- **Rule:** read-only, auto-generated by `/aid-init`

### Active Work
- **Path:** `.aid-o/work/active.md`
- **Read at:** every run start
- **Write at:** every run end (update current focus, recent work, next steps)
- **Rule:** keep under 200 lines, archive entries older than last 3 tasks

### Backlog
- **Path:** `.aid-o/work/backlog.md`
- **Written by:** [Curator agent](../agents/curator) (post-gate)
- **Format:** sections for Bugs / Features / Refactoring / Performance with IMP-NNN entries
- **Rule:** do not write directly, do not delete entries

### Quick Logs (FAST MODE)
- **Path:** `.aid-o/work/quick/Q-NNN.md`
- **Auto-created by:** `/aid-do`
- **Rule:** read-only for agents

## Timeline Queries (EPIC MODE)

Check current task status:
```bash
cat .aid-o/work/evidence/{epic_id}/{run_id}/state.yaml
```

Get recent events:
```bash
tail -20 .aid-o/work/evidence/{epic_id}/{run_id}/timeline.jsonl | jq .
```

## Optional: Shared Brain (Qdrant)

If `integrations.yaml` has `qdrant.enabled: true`:
- Use `qdrant-find` for cross-project knowledge search (lessons, patterns, decisions)
- Use `qdrant-store` after EPIC completion to index lessons
- If Qdrant is unavailable: skip silently, never block on Qdrant

## Rules

1. **ALWAYS** read `project.yaml` + `active.md` at run start (mandatory)
2. **NEVER** write to `project.yaml` (read-only, auto-generated)
3. **NEVER** delete entries from `backlog.md`
4. Qdrant is optional -- all workflows work without it
