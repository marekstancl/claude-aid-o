# Improvement Proposals -- Removed in v2.0.0

This skill was consolidated into the [Curator](../agents/curator) agent in v2.0.0.

The standard format for `improvement_notes`, collection protocol, deduplication rules, and backlog integration are now part of the Curator agent's 7-phase workflow and the [Agent Protocol](./agent-protocol) output format.
