# /aid-epic-status -- Removed in v2.0.0

This command was removed in v2.0.0. Use [/aid-status](./aid-status) instead.

`/aid-status` provides a unified view of active tasks, quick logs, and queue. Use `/aid-status <task-id>` for detailed FSM state, step progress, and timeline events.
