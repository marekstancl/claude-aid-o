# /aid-run-epic -- Removed in v2.0.0

This command was removed in v2.0.0. Use [/aid-run](./aid-run) instead.

`/aid-run` executes the same task pipeline with a simplified 6-state FSM. Use `/aid-run <task-id>` for manual mode or `/aid-run --auto` for autonomous execution.
