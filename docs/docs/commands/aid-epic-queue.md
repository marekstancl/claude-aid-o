# /aid-epic-queue -- Removed in v2.0.0

This command was removed in v2.0.0. Use [/aid-status](./aid-status) instead.

Queue management is now part of `/aid-status`. Use `/aid-status queue` for the queue view, `/aid-status queue add <path>` to add tasks, and `/aid-status queue pause|resume` to control auto-pickup.
