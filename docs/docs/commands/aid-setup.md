# /aid-setup -- Removed in v2.0.0

This command was removed in v2.0.0. Use [/aid-init](./aid-init) instead.

`/aid-init` now handles both workspace initialization and interactive onboarding -- stack auto-detection, gate configuration, and project profile generation are all built in.
