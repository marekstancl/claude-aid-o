# /aid-analytics -- Removed in v2.0.0

This command was removed in v2.0.0. Use [/aid-audit](./aid-audit) instead.

Performance analytics functionality is now part of `/aid-audit`. Run `/aid-audit efficiency` for token usage analysis or `/aid-audit full` for a complete project health check including performance metrics.
