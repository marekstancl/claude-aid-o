# /aid-plan-epic -- Removed in v2.0.0

This command was removed in v2.0.0. Use [/aid-plan](./aid-plan) instead.

`/aid-plan epic <plan-file>` generates EPICs from a plan file. Run `/aid-plan` with no arguments for auto-detection of the appropriate mode.
