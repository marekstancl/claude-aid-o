# /aid-brainstorm -- Removed in v2.0.0

This command was removed in v2.0.0. Use [/aid-plan](./aid-plan) instead.

`/aid-plan` merges brainstorming, plan writing, and EPIC generation into a single command with auto-detection. Run `/aid-plan brainstorm "topic"` for the same 8-step interactive flow.
