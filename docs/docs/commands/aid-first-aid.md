# /aid-first-aid -- Removed in v2.0.0

This command was removed in v2.0.0. Use [/aid-run --auto](./aid-run) instead.

Autonomous execution is now a flag on `/aid-run`. Run `/aid-run --auto` for the same behavior -- S-effort auto-fixes, L-effort always escalates to PM.
